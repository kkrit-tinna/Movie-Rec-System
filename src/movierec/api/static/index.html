    How does this work?

    Similar details compares the specific words in each film's title, tagline, plot summary and genres (TF-IDF). Similar feel compares overall meaning using pretrained GloVe word vectors, averaged across each film's words. Both were evaluated on held-out TMDB keywords; Similar details scored higher, so it's the default.

    How does free-text search work?

    Your words are compared with the words in each film's title, tagline, plot summary and genres (TF-IDF, the same representation as Similar details). Rare words count for more than common ones, and films are ranked by how closely their words match yours. It matches words, not meaning: a film whose description doesn't use your words won't appear.
